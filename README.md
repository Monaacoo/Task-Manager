# Task Manager CLI (C++)

A simple command-line task manager built using C++ and STL.

## Features
- Add tasks
- List tasks
- Mark tasks as completed
- Remove tasks

## Concepts
- STL (vector, string)
- Structs and modular design
- Basic CRUD operations

## How to Run in VsCode

```bash
g++ main.cpp task.cpp -o task-manager
./task-manager
